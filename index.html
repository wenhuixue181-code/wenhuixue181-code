1. 绿筑智选 (GreenBuild AI) —— 可定义目标约束下混凝土配方仿真设计与决策平台
Python · FastAPI · Pydantic · ExtraTrees 多龄期建模 · 残差分位数不确定性评估 · SQLite · 阿里云ECS
🚀 进入阿里云线上真实系统 (免登录) ↗

基于 Meta Research 开源项目 BOxCrete (SustainableConcrete C1–C80) 真实试验数据构建。面向建材研发中早龄期信息演进与低碳筛选需求，独立开发包含「混凝土配方智能设计、多龄期性能建模分析、实验记录与预算台账、AI 实验分析助手、材料配方总库」的全栈研发辅助决策平台。

  • 多龄期递进建模与 90% 置信下界风险评估：严格按 48 训练 / 16 校准 / 16 独立测试集隔离划分，构建「仅配方信息 ➔ 已测 1 天 ➔ 已测 1+3 天」三阶段 ExtraTrees 递进回归模型；基于独立校准集残差分位数生成 0–28 天强度概率预测区间与 90% 下界。
  • 三级启发式低碳优选与闭环生成：采用「01 性能约束过滤 ➔ 02 预测下界不确定性分级（可优先复核 / 需要补测 / 不优先）➔ 03 同优先级 GWP 碳排排序」逻辑；支持约束采样、实验结果回填邻域生成与 AI 实验分析助手。
🟢 线上生产环境已部署运行：支持免登录直接体验 GWP×强度散点交互、0–28天概率预测曲线、低碳方案优选与实验分析助手

2. VirtualCloset —— 基于 Android 的智能虚拟衣橱与场景穿搭推荐系统（大赛获奖作品）
Java · Android Studio · SQL Server / SQLite · 多城市实时天气 API · 社交动态流

中国大学生计算机设计大赛参赛作品（获华北五省及港澳台计算机应用大赛二等奖）。针对日常衣物管理繁琐与穿搭决策痛点，开发集“7大品类数字化衣柜管理、多城市实时天气感知穿搭推荐、衣友圈社区动态广场”于一体的原生 Android 应用。

  • 多城市天气 API 联动与智能穿衣指数：接入实时天气 API 动态渲染城市温湿度与体感温度（如北京 13°C 与银川 25°C 场景自适应），自动生成分季节穿衣贴士。
  • 7大品类衣柜管理与6宫格成套搭配：支持外套、上衣、裤子、长款衣、配饰、鞋子分类上传与网格管理；基于 7 大风格标签（春夏/秋冬/复古/淑女/田园/街头/混搭）一键生成 6 宫格成套穿搭方案。
