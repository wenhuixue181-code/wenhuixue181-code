2. VirtualCloset —— 基于 Android 的智能虚拟衣橱与场景穿搭推荐系统（大赛获奖作品）
Java · Android Studio · SQL Server / SQLite · 实时天气 API · 第三方社交分享 SDK

中国大学生计算机设计大赛参赛作品（获华北五省及港澳台计算机应用大赛二等奖）。针对日常衣物管理繁琐与穿搭决策痛点，开发集“数字化衣柜分类管理、实时天气感知穿搭推荐、穿搭动态社交广场”于一体的原生 Android 应用。

  • 三层视图架构与多机型适配：基于 Java 与 Android Studio 设计“登录认证、主控动态看板、侧边栏功能矩阵”架构，采用 Nine-Patch (.9.png) 与屏幕密度动态换算实现多分辨率自适应。
  • 天气 API 联动与多维标签匹配：接入实时天气 API 推送温湿度状态，结合衣物风格（休闲/复古/通勤）与季节属性标签库，实现免试穿场景化服饰搭配推荐及社区动态筛选。

左侧为基于设计文档还原的 Android 客户端交互原型，您可以直接点击手机屏幕内的按钮体验三大核心业务流：
