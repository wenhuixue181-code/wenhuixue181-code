2. VirtualCloset —— 基于 Android 的智能虚拟衣橱与场景穿搭推荐系统（大赛获奖作品）
Java · Android Studio · SQL Server / SQLite · 多城市实时天气 API · 社交动态流

中国大学生计算机设计大赛参赛作品（获华北五省及港澳台计算机应用大赛二等奖）。针对日常衣物管理繁琐与穿搭决策痛点，开发集“7大品类数字化衣柜管理、多城市实时天气感知穿搭推荐、衣友圈社区动态广场”于一体的原生 Android 应用。

  • 多城市天气 API 联动与智能穿衣指数：接入实时天气 API 动态渲染城市温湿度与体感温度（如北京 13°C 与银川 25°C 场景自适应），自动生成分季节穿衣贴士。
  • 7大品类衣柜管理与6宫格成套搭配：支持外套、上衣、裤子、长款衣、配饰、鞋子分类上传与网格管理；基于 7 大风格标签（春夏/秋冬/复古/淑女/田园/街头/混搭）一键生成 6 宫格成套穿搭方案。
